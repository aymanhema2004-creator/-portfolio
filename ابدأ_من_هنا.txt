Ayman Ibrahim — Portfolio V6 (Arabic / English)
================================================

النسخة الجديدة:
- عداد الزوار الحقيقي (تقريبًا عدد المتصفحات المختلفة).
- عدد إعجابات مشترك بين الزوار + زر قلب للتسجيل/الإلغاء.
- عدد اللايكات يتحدث فور الضغط، ويتجدد تلقائيًا في الصفحة المفتوحة.
- صور Mr. Ayman Academy الأصلية + صور Nexora POS التصورية.
- وسائل التواصل الحقيقية والواتساب كوسيلة أساسية.
- ثنائي اللغة عربي / إنجليزي.

شغل الموقع:
فك الضغط وافتح index.html في Chrome.

مهم بخصوص العداد واللايكات:
لن تظهر أرقام مختلقة؛ ستظهر شرطة (—) إلى أن تربط Supabase.
1. افتح ملف "خطوات_النشر_والعدادات.md" واتبع الشرح.
2. افتح SQL Editor في مشروع Supabase (يفضل مشروع منفصل للبورتفوليو).
3. نفّذ النص الموجود في supabase-setup.sql مرة واحدة.
4. حط Project URL و Publishable Key العام في portfolio-stats-config.js.
   لا تضع أبدًا secret key أو service_role في هذا الملف.
5. ارفع ملفات الموقع إلى GitHub Pages.

النشر على GitHub Pages:
الملف "خطوات_النشر_والعدادات.md" فيه خطوات دقيقة.
باسم المستخدم GitHub الخاص بك إذا سميت المستودع portfolio، سيكون الرابط
المتوقع بعد النشر:
https://aymanhema2004-creator.github.io/portfolio/
(هذا ليس رابطًا مُفعَّلًا أو تم التحقق منه بعد.)

عدد الزوار ليس عدد البشر الموثقين؛ يعتبر كل متصفح بمعرف محلي زائرًا واحدًا.
وإزالة بيانات الموقع من المتصفح قد تعيد احتساب الزائر.
